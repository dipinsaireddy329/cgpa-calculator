# 🎓 Advanced CGPA Calculator

A modern, responsive **CGPA Calculator & Target CGPA Planner** built using **HTML, CSS, and JavaScript**. It helps students calculate their CGPA instantly, plan future semesters, and track academic progress with a clean and interactive interface.

---

## ✨ Features

- 🎯 Instant CGPA Calculation
- 📚 Support for Up to 8 Semesters
- 📈 Target CGPA Planner
- 📊 Animated Progress Bar
- 🏆 Grade Classification
- 💎 Modern Glassmorphism UI
- 📱 Fully Responsive Design
- 💾 Local Storage Support
- 🎨 Beautiful Blue Theme
- ⚡ Fast & Lightweight

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/dipinsaireddy329/advanced-cgpa-calculator.git
```

### Navigate to the Project

```bash
cd advanced-cgpa-calculator
```

### Run the Project

Simply open **index.html** in your preferred web browser.

No additional installation or dependencies are required.
