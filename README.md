# 🎓 Advanced CGPA Calculator

A modern CGPA Calculator and Target CGPA Planner built using HTML, CSS and JavaScript.

## Features

- Calculate CGPA instantly
- Supports up to 8 semesters
- Target CGPA Planner
- Animated Progress Bar
- Grade Classification
- Glassmorphism UI
- Responsive Design
- Local Storage Support
- Modern Blue Theme

## Technologies Used

- HTML5
- CSS3
- JavaScript
